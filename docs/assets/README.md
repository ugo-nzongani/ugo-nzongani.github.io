Put your portrait in this folder, for example `photo.jpg`, and set
`profile.photo` to `"assets/photo.jpg"` in `../site-data.js`.

The current `profile.svg` is an initials placeholder, not a photograph.
You can replace it with a different SVG or point the configuration to a JPG,
PNG or WebP image. Use a square image for an easy circular crop.

The icons and DM Sans fonts are bundled locally. Their licenses are in
`icons/LICENSE-lucide.txt` and `fonts/OFL.txt`.
